About this Project

Architecture overview, ML pipeline, dataset details, and technology stack

Project Purpose

Unexpected industrial equipment failures cause high repair costs, emergency maintenance delays, and lost manufacturing output. This system leverages supervised machine learning to continuously process sensor signals and predict impending failure risks before critical downtime occurs.

AI4I 2020 Dataset

  • 10,000 industrial machine telemetry records
  • Features: Air & Process Temp [K], Speed [rpm], Torque [Nm], Wear [min]
  • Product Variants: L (Low 50%), M (Medium 30%), H (High 20%)
  • Failure Modes: TWF, HDF, PWF, OSF, RNF
  • Target: Binary — 0 (Normal) / 1 (Failure)
